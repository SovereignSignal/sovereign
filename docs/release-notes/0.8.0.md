## Sovereign 0.8.0: memory you can audit, in plain files you own

Every AI tool you use starts each session knowing nothing about you. Most memory tools fix that by writing on their own, with no step where you decide what's true. Sovereign keeps your context in a folder of Markdown files on your Mac that your tools read before they work and add to as they go.

A background curator drafts short cards from what your tools save, and at first nothing becomes trusted until you approve it. Every trusted card names its source, and an append-only decisions log records who let it in and when. After ten clean routine decisions you can let routine cards land on their own, and one button sends the curator back to asking first. This release lets any MCP client read your trusted cards, and lets a new archive start with what ChatGPT remembers about you.

### Your first five minutes

1. Download the zip below, unzip, move `Sovereign.app` to Applications, open it.
2. Create an archive (a folder in your home directory works well).
3. Connect Claude Code when asked. It now reads your archive at the start of every session.
4. In Settings, Curator: pick a provider (Anthropic by default, also OpenAI, Google Gemini, xAI Grok, or Muse). No key yet? "Get your key" walks you through the provider's own pages, including a spend limit. Paste the key and turn the curator on. The key stays in your login Keychain.
5. Tell Claude Code something durable worth remembering. Choose "Curate now", then approve the drafted card in Review.
6. Open a new Claude Code session. It starts out knowing what you approved.

**Requirements:** Apple Silicon Mac, macOS 13 or later, Claude Code, and an API key from your chosen provider. Out of the box nothing leaves your Mac: no account, no telemetry, no server. The only outbound traffic is the curator you turn on, sending new material to your one chosen provider under your own key. An archive marked local-only refuses every hosted model.

**SHA-256:** `<sha256>` (also in the `.sha256` asset)

This is a closed beta. The archive format is plain Markdown in five folders and does not depend on the app. Signed with Developer ID, notarized by Apple, and stapled.

### What changed in 0.8.0 (build 51)

- `sov mcp`, a read-only MCP server any MCP client can use. Four tools (`load_context`, `read_card`, `search_cards`, `list_cards`) serve the trusted layer only, each card with its path and content hash. No symlink is followed out of the archive, an ambiguous slug is refused, anything shaped like a secret is redacted on the way out, and there is no write path.
- Import from ChatGPT, in Settings › Import or with `sov import chatgpt`: a prompt for ChatGPT, a preview, then one untrusted capture per memory for the curator to judge. Re-importing brings in only what changed.
- Settings › Curator walks a newcomer through getting a key from each provider: the steps, the provider's own key and spend-limit pages, and where a provider documents no spend limit, it says so.
- A new archive's curator now judges what connected tools saved before it was turned on, such as existing Claude Code memory, 20 files a pass. Before, it looked back only two days.
- Check for updates in Settings installs the latest signed release after verifying its signature and notarization.
- Capture titles and origins that YAML would misread are quoted, so a capture's labels always parse.
- The README, the welcome screen and these notes now lead with what Sovereign is for: memory you can audit, kept as plain files you own.
